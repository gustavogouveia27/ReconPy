# 🔎 ReconPy

### Python Reconnaissance Tool

ReconPy é uma ferramenta de reconhecimento desenvolvida em Python
com o objetivo de auxiliar no levantamento inicial de informações
sobre domínios e aplicações web.

O projeto foi desenvolvido como parte dos meus estudos de Python,
redes, DNS, HTTP e fundamentos de Pentest.

---

## 🚀 Funcionalidades

Atualmente o ReconPy possui:

- 🌐 Resolução de informações do domínio
- 🔎 Descoberta básica de subdomínios
- 🧩 Detecção básica de tecnologias
- 🔗 Coleta de URLs encontradas no HTML
- 🛡️ Análise de cabeçalhos HTTP
- 🔄 Execução contínua para analisar múltiplos domínios
- ⚠️ Tratamento básico de erros

---

## 🛠️ Tecnologias utilizadas

O projeto utiliza bibliotecas nativas do Python:

- `socket`
- `urllib`
- `re`

Não é necessário instalar frameworks externos para executar a versão atual.

---

## 📋 Requisitos

- Python 3.x
- Windows, Linux ou macOS
- Conexão com a Internet

Verifique sua versão do Python:

python --version

## ▶️ Como executar

### 🪟 Windows

Abra o CMD ou PowerShell na pasta do projeto e execute:

```bash
python recon.py
```

🐧 Linux / Kali Linux
```bash
Abra o terminal na pasta do projeto e execute:

python3 recon.py

```
